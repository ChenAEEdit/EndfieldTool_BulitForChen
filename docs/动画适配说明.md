## 1. 使用步骤

1. 打开 `D:/AAAChatGPT/EndfieldCharacterTool-Framework/EndfieldChenTool.exe`，窗口应显示“动画预览场景 0.9.0”。
2. 在“对象与导出”载入任务，选择实际模型根节点、对应 Avatar 和需要的动画。
3. 进入“动画适配”，确认单位倍率、根位移、排除规则，按需勾选“生成可切换、暂停和重播的独立预览场景”。不同类型的动作建议分包处理。
4. 点击“生成 Unity 适配包”。工具重新导出精确选择的模型和原始动画，保留来源快照、摘要、规则和选择；这一步只准备文件。
5. 核对页面显示的目标项目和编辑器，然后保存并关闭这个项目的 Unity 编辑器。当前项目为 `D:/Unity 3D/Projects/Codex_ZMD`。路径来自已保存计划，修改环境设置只影响之后建立的新计划。
6. 点击“导入并生成适配”。工具检查项目版本、占用和文件摘要，复制独立包，启动 Unity 后台生成。项目已打开时会停止并提示，保留你的编辑。
7. 等待导入和编译完成。只有本次 Unity 调用回执、任务／运行编号、配置与源文件、动画数量、输出路径、长度和 SHA256 全部匹配，才标记“已适配 · 未验证播放”。本包已有完整结果时，核对后明确显示复用，不会重新覆盖生成。
8. 点击“打开生成目录”查看动画、控制器、Prefab 和报告；勾选场景时还会有 `CharacterPreview.unity`，可点击“定位预览场景”。在同一 Unity 项目打开它、进入 Play 后，在 Game 视图切换、暂停、重播、调速、拖动时间或逐帧查看。失败时查看 Unity 日志和任务记录。

仍可手动复制包内完整 `Assets`，在 Unity 选择 `adaptation.json`，执行 **Endfield Character Tool → 适配所选配置并生成预览 Prefab**，然后回到工作台读取结果。单独读取不启动 Unity。0.8.0 包继续支持自动生成，不自动添加场景；需要场景时准备新的 0.9.0 包。0.7.0 包仍可手动使用。

不覆盖原始 `.anim`，也不重建已有行走或待机场景。生成目录已有输出时会停止，请从工具生成新包，以保留已有修改。修改规则请在工具内重新生成包；自行编辑 Unity 中的配置会与工作台记录的摘要不同，结果回读会拒绝确认。

## 2. 设置是什么意思

| 设置 | 处理 |
| --- | --- |
| 模型导入倍率 | Unity FBX 导入器 `globalScale`；一般默认 1，仅当前已收录且版本、模型 PathID 匹配的陈千语模型预填 100 |
| 动画位置倍率 | 对 Transform 位置关键帧及其切线应用倍率；默认 1，不改变旋转和缩放 |
| 首帧位移归零节点 | 可选明确路径，如 `Root`；该节点各位置轨道减去首帧值，不将所有骨骼位置归零 |
| 排除后代 | 每行一个父路径，仅排除它的后代轨道，保留该父节点本身；例如核对后可用于保留头部运动而排除共享面部子骨骼 |
| 排除节点 | 每行一个明确路径，仅排除对应节点的轨道；适用于经独立诊断确认的辅助骨骼，不按名字自动全局排除 |
| 忽略未匹配轨道 | 默认关闭；缺失或不唯一的路径使该片段适配失败。明确勾选后跳过并完整记录，不能等同于完整还原 |
| 移除场景对象位置 | 默认开启，只去掉空路径的外层场景对象位置轨道，保留骨架节点位移 |
| 强制循环 | 默认关闭，沿用源动画循环设置；开启时强制循环，不会自动修复首尾姿势接缝 |
| 生成预览场景 | 默认开启；在独立 Generated 下保存相机、照明、Prefab 实例和播放面板；不采样后保存动画帧 |

当前只实现 **Generic 直接 Transform 曲线**，排除 Animator 肌肉与根通道，不提供自动 Humanoid 重定向。路径优先精确匹配，其次只接受唯一的层级后缀匹配；不唯一时不会取第一个。

曲线值与时间必须有限，时间不得逆序；非有限切线修整时保留为常量侧切线并记录。使用 Unity 原生 API 重建动画和四元数连续性，不直接修改原始 YAML 内部绑定表。生成 Prefab 使用独立预览场景，不采样后保存动画姿势到原场景。

**Generic 不是所有动作的最佳模式。** 本次膝部检查中，陈千语专属行走当前 Humanoid 预览的局部形变指标好于直接 Generic 源动画；不能用本页生成结果无条件替换现有专属行走。共享、专属、附加动作、面部、扭转及修正骨骼需要分别确认。详见[膝部诊断记录](D:/AAAChatGPT/2026-10-23/ni/EndfieldChenTool/docs/膝部诊断记录.md)。

## 3. 输出和状态

```text
tasks/<任务>/objects/
  result.json                         最近一次对象操作
  preparation.json                    最近一次适配包操作，不被普通原始导出覆盖
  unity-last-run.json                  最近一次自动导入／生成记录，独立于原始导出状态
  <运行>/
    selection.json                    模型、Avatar、动画及明确设置
    operation.json                    本次真实状态
    unity-runs/<调用编号>/
      run.json                        阶段、失败／取消、项目、退出码及复用状态
      unity.log                       Unity 本次启动日志
      native-completion.json          Unity 入口实际执行后才产生的调用回执
      project-backup/                 更新已知版本共享编辑器脚本时的备份
    exports/
      model/                          原始 FBX、贴图、元数据
      animations/                     原始解码动画
      unity-package/
        使用说明.md
        Assets/
          EndfieldCharacterWorkbench/Editor/CharacterAnimationAdapter.cs
          EndfieldCharacterWorkbench/Runtime/CharacterPreviewControls.cs
          EndfieldCharacterExports/<任务短ID>_<运行ID>/
            adaptation.json
            Model/
            Sources/
            Generated/                在 Unity 中生成后出现
              CharacterPreview.unity  勾选生成预览场景时出现
```

| 状态 | 含义 |
| --- | --- |
| `exported_unverified` | 原始导出完成，尚未适配 |
| `unity_prepared` | 文件、规则和 Unity 编辑器入口已准备，`adapted=false` |
| `adapted_unverified` | 读取并核对 Unity 生成的本次结果，`adapted=true`，`playbackVerified=false` |
| `partial` / `failed` / `cancelled` | 部分失败、失败或取消；不能标为全部适配成功 |

包内输入复制前后核对 SHA256；Unity 生成前后再次核对输入和配置摘要。自动流程使用任务锁和独立项目导入锁；结果回读检查 Bundle 运行记录、计划摘要、项目实际配置和源文件、所选动画身份及所有输出。普通原始导出、适配包和 Unity 调用各自保留记录。失败或取消保留适配包，不能算作本次生成成功。

已存在且摘要相同的源文件可以复用。输出已被修改、部分生成或来源不符时，请重新准备新包；本版不自动删除原输出。共享编辑器脚本相同时复用，工具记录的原版本或已知 0.7.0 版本在更新前备份；未知或手工修改的脚本会停止导入并保留。

自动流程的取消只结束本次启动的 Unity 进程及其子进程，已打开的其他编辑器不受影响。单次 Unity 运行上限 60 分钟，超时保存日志并结束本次进程。中断后的临时目录可能保留在项目 `Library/EndfieldCharacterWorkbench/staging`，不影响原资源；当前不提供自动清理。

## 4. 实现入口及限制

- `Framework/AnimationPage.cs`：设置、生成包和结果读取页面。
- `scripts/prepare_unity_adaptation.py`：准备独立包与来源配置；由对象流程 `prepare` 模式调用。
- `templates/workspace/CharacterAnimationAdapter.cs`：Unity 原生曲线转换、控制器、Prefab 和报告。
- `Framework/Services/UnityAdaptationResults.cs`：严格核对并记录本次原生适配结果。
- `Framework/Services/UnityAdaptationRunner.cs`：项目／文件检查、独立导入、脚本备份、后台进程、取消、回执、复用及运行日志。

已接入可选预览场景，但尚未进行实际播放验证，也没有复原游戏膝部修正求解器、布料、IK 或专用着色器。场景使用基础照明与导入材质。当前单个包统一使用一套规则；规则不同的片段应分包，不自动按动画名称推断处理方式。
