# 新增角色正式工作台接入验收（2026-10-27）

## 交付内容

- 工作台增加“自动关联专属待机”。关联器依据层级根节点、模型骨骼引用、Avatar 和 Animator Controller 的实际引用解析模型与两条专属待机；模型重复、引用缺失、层级矛盾、控制器证据不足或待机不唯一时拒绝自动选择，并给出失败原因。
- 单位推导接入生成流程，默认启用。使用目标模型的蒙皮绑定段长、语义人体映射和待机动画位置曲线测量结果推导模型导入倍率及动画位置倍率；推导依据、误差、测量段数和每条动画的结果写入 `Generated/unit-inference.json`。
- 严格轨道模式保持默认。未匹配或不支持的轨道在严格模式下使任务失败；用户显式开启部分轨道后才允许省略，并在审计报告中逐项记录理由。
- 仅自动接入角色自己的 `overview_loop` 与 `relax_loop` 待机。本次不对共享走路动画作自动适配结论。
- 工作台版本提升到 `0.13.0-role-unit-inference`。
