## 操作步骤

1. 打开 `D:\AAAChatGPT\EndfieldCharacterTool-0.12.0\EndfieldChenTool.exe`；填写游戏和输出路径，选择与工程一致的 Unity 编辑器。
2. 选择角色及资源，生成并载入提取任务，解析实际对象。选择模型、实际关联 Avatar 和要播放的动作。
3. 本轮三个模型均使用模型导入倍率 **100**、动画位置倍率 **1**，请在高级设置核对。专属 Generic 动作保持默认直接绑定；共享动作显式选择有证据的源骨架候选。本轮女性共享样例使用 `SK_actor_female`，男性共享样例使用 `SK_actor_male`。同覆盖候选不会自动选定，其他骨架需另行验证。
4. 默认严格模式遇到缺少目标节点或参考证据会停止。明确接受部分轨道不输出时，勾选“忽略未匹配轨道并记录”，再生成新的独立适配包。
5. 保存并关闭目标 Unity 编辑器，点击“生成 Unity 预览”。完成后先看输出/未输出数量，再在同页“轨道明细”查看完整路径、属性及原因；可按名称、哈希搜索。
6. 点击“打开并播放预览”，观察完整循环、脸、手脚和膝盖。已生成内容不覆盖重建；修改规则后建立新包。
