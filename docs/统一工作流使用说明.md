## 1. 从哪里打开

继续使用原来的运行入口：

`D:\AAAChatGPT\EndfieldCharacterTool-Framework\EndfieldChenTool.exe`

窗口标题应为“终末地角色工作台 · 统一工作流 0.11.0”。若已有旧窗口，请关闭后重新打开。

## 2. 四个入口

| 入口 | 用途 |
| --- | --- |
| 角色与动作 | 选择资源、准备角色、选择动作、生成预览或导出 |
| 任务与结果 | 读取历史任务，继续准备资源，打开该任务的动作列表 |
| 设置 | 设置新任务默认的游戏、工作区及 Unity 路径 |
| 帮助与日志 | 在当前窗口阅读日志、结果报告和说明 |

运行时不自动切换页面。底部显示进度，并固定提供“取消任务”。切换到日志后再点击“角色与动作”，回到离开前的步骤。

主窗口不再打开另一个陈专用窗口。历史专用流程仍保留在命令行兼容入口 `--legacy`，不作为主流程使用。

## 3. 新建任务

1. 在“角色与动作”的第 1 步选择角色及资源。
2. 进入第 2 步，核对顶部的新任务默认项目，点击“准备角色与动作”。工具自动提取资源并解析实际对象；此时还没有导出 FBX 或生成 Unity 动画。
3. 完成后，主动点击第 3 步“选择动作与预览”。
4. 左侧选择模型和骨架、勾选动作；右侧点击“生成 Unity 预览”。目标项目的 Unity 编辑器需要先保存并关闭。
5. 工具自动准备适配包、导入现有项目、执行原生生成并核对结果。成功后显示动画数量、目标项目及场景路径。
6. 点击“定位预览场景”，然后在对应 Unity 项目中打开场景并 Play。生成文件通过核对不等于姿势、关节、材质及实际播放均正确。

高级参数默认收起：模型与位置倍率、排除骨骼、位移归零、未匹配轨道处理，以及单独准备包、导入已有包和核对结果等入口。需要原始 FBX／动画时，使用左侧“导出所选对象”。

## 4. 使用现有任务

进入“任务与结果”，选中任务，点击“打开角色与动作”。已有对象列表会载入；如果还未完成提取或解析，先点击“继续准备资源”。

默认优先显示与当前角色代码名称相关的动作，也可筛选待机／休息、行走／移动或全部动作。名称相关及动作分类均为名称筛选，不能证明骨架兼容。没有名称关联项时显示全部。切换筛选不会清除已勾选项，界面显示筛选外仍勾选的数量。

模型仅在计划标识唯一匹配或仅存在一个模型候选时自动选取。Avatar 的自动选择仍依据实际 Animator 引用，不按相似名称猜测。

## 5. 更换 Unity 项目

窗口顶部区分“新任务默认项目”和“当前任务目标项目”。

- “设置”页面保存的新项目只影响以后创建的任务。
- 已有任务需要先在任务列表选择该任务，或载入它的动作列表，再点击顶部“更换当前任务项目”。
- 在主窗口内选择项目和对应编辑器，点击“保存到当前任务”。“填入默认项目”只是填入设置页路径，仍需明确保存。
- 工具核对已有项目结构、编辑器路径及版本；任务正在运行时禁止更改目标。
- 切换目标不移动或删除旧项目中的生成物。需要在新项目执行生成及结果核对；任务列表会提示目标已更换、待生成。

新目标保存在任务目录的 `unity-target.json`，绑定任务编号与原计划 SHA256。原 `plan.json` 不修改，因而无需为切换 Unity 项目重新提取 Bundle。默认设置继续保存在本机应用数据目录下 `EndfieldCharacterTool/settings.json`。

目标配置不是适配成功证明。导入、结果读取、诊断报告和场景定位都使用该任务的当前目标，历史运行记录保留各次实际项目。

## 6. 部分动画失败

右侧直接显示“已转换 / 未完成”的数量及失败动画名称、原因、未匹配路径数量。日志文件也可在“帮助与日志”中读取，不会自动打开外部编辑器。

当前原生生成器仍要求所选动画全部完成才生成完整预览。若部分动作已转换，界面提供“仅用已转换项重新生成”：

1. 由用户点击后，重新读取并核对当前任务和包的报告归属、配置摘要及动画身份。
2. 恢复原包模型、Avatar 和适配参数，明确改为只选择报告中已转换的动作。
3. 建立新的独立包，再完成生成及严格核对；保留原失败包和日志。

此操作不会擅自打开“忽略未匹配轨道”，不会把不完整的旧结果认定为完整成功，也不代表已验证播放。没有可用报告或没有已转换项时，重试按钮不可用。

## 7. 本次源码变更

- `Framework/WorkspaceShell.cs`：四入口导航、当前任务及项目上下文、内嵌目标编辑、折叠区与滚动容器。
- `Framework/WorkspaceForm.cs`：移除自动跳页和消息框、底部取消、资源准备自动接解析、精简任务操作。
- `Framework/ObjectPage.cs`：同页模型／骨架／动作选择、名称筛选、隐藏勾选计数、一步预览。
- `Framework/AnimationPage.cs`：主按钮、高级单步入口、结果摘要及仅用已转换项重试。
- `Framework/Services/UnityTaskTarget.cs`：任务目标独立持久化、任务锁和路径校验。
- `Framework/Services/UnityFailureSummary.cs`：读取并解释逐动画生成报告，不能替代完整输出校验。
- 生成执行器、结果读取器及诊断导出：接入当前任务目标；Unity 非零退出时优先解释动画完成数量。

界面版本升为 0.11.0。原生适配模板和包协议本轮未改版，仍生成 0.10.0 格式的原生配置；继续兼容现有 0.8 / 0.9 / 0.10 适配包。
