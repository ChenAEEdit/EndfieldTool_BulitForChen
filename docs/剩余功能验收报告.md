## 首批发现与修复（历史过程，最终状态以上表为准）

### 仅生成预制体的菜单错误

旧版生成成功后无条件调用打开预览场景；关闭预览选项时，已有的预制体被误报为失败。
在新建的“剩余验收 B 20261026”工程实际复现。现在共用完整结果校验：启用场景时打开场景，未启用时选中已核对的预制体。
两次重复执行菜单通过，旧生成物未改动；主动请求播放无场景包时仍清楚提示缺少预览场景。

### 中文路径日志

中文和空格工作区能成功提取、导出、生成，但两个导出器输出控制台日志使用系统编码，Python 按 UTF-8 读取后路径乱码。
修正三个导出器控制台为 UTF-8；三个组件均已重新编译打包，后续实际解析和导出日志显示完整中文路径。文件本身与 JSON 路径未损坏。

### 小窗口高级区

1050×800 窗口展开高级区后，原来存在两层紧邻滚动条，验收中的实际拖动在两层之间反复跳转，无法到达“核对已有结果”。
高级预览设置改为由外层统一滚动，真实拖动后点击该按钮、成功读取已有结果。100% 实测通过。
高 DPI 通知暴露字体与固定控件尺寸不一致。最终修复了单行／单列布局隐式 AutoSize 导致的溢出，以及折叠区沿用初始高度的问题；模拟 150%、200% 与真实 150% 复测均通过。真实 200% 尚未验证。

### 跨角色模型候选

完整只读扫描 42 个 CHK，约 40 GiB，得到 152 个角色名称候选、原始 2649 项资源；重新扫描复用 42 个 CHK 缓存，无需重复读完整文件。
艾维文娜最初仅得到 50 条动画对象，没有实际模型：名称在控制器中出现，模型位于直接引用控制器的包。
增加清单直接反向引用候选（每个种子最多 64 个，仍标为 NameCandidate），重新提取后确认艾维文娜和黎风的真实模型及关联 Avatar。
不是按这两个角色写死资源包；扩展依据当前清单引用，仍不代表候选均为模型或动画兼容。

### 共享动作边界

为艾维文娜显式加入同版本的共享 female_walk，模型及两条专属待机已生成；共享行走因 163 条未知路径失败。
检查当前实际加载的两个 Avatar 表后，这些路径无法由任一个唯一解析。未开启忽略未知轨道，未以替换成手势或待机冒充移动验收。
后续继续核对动作原骨架／路径来源及在不同角色上的适配条件。

尝试仅从精确模型层级补全路径 CRC，没有减少陈的 164 条未知路径。实验代码已撤回，避免增加未证明有效的机制。
旧专用 `pipeline.py:resolve_animation` 会排除不在目标 Avatar TOS 中的路径；这是旧专用流程成功的一项明确限制，不能据此宣称通用框架保留了共享动画的全部轨道。
