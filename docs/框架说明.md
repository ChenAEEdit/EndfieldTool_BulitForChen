## 2. 当前能操作什么

| 页面 | 当前实现 |
| --- | --- |
| 角色与资源 | 检查索引兼容性；扫描本机游戏、取消及重新扫描；读取配置／JSON 索引；搜索角色并筛选资源；查看来源、关联依据和依赖 |
| 提取计划 | 勾选资源，展开已记录的 Bundle 依赖；配置动画自动包含已配置模型及 Avatar，名称候选模型需自行选择；保存独立任务计划 |
| 任务记录 | 执行／重试 Bundle 提取、取消，查看实际结果和文件列表，打开输出目录及结果 |
| 环境与已有工具 | 填写游戏、输出、Unity、Blender 路径，保存独立设置；打开既有陈千语提取窗口 |
| 运行日志 | 扫描、兼容性检查和提取的进度、日志及结果入口 |
| 对象与导出 | 列出实际模型、网格、Avatar 和动画；按来源和 PathID 精确选择；导出 FBX／原始 `.anim`，查看结果与部分失败 |
| 动画适配 | 设置单位、根位移与排除节点；生成独立包；自动导入既有项目并回读；可选独立播放场景；查看日志、生成目录及定位场景；保留手动回读 |

首次加载的数据来自 `profiles/chen.json`，只有陈千语模型、Avatar 和两条行走。这表示工具已收录配置，没有执行游戏扫描，也没有重新证明资源能解码或播放。六条专属待机仍通过现有 Unity 项目场景／菜单访问。

选择资源后，在“提取计划”点击“执行 Bundle 提取”，或先保存计划，再从“任务记录”继续／重试。Bundle 完成后在任务记录点击“解析 Bundle 对象”，然后从“对象与导出”选择模型根节点、Avatar 和动画进行导出。此阶段不生成 Unity 场景，原始动画仍需适配。原陈千语窗口沿用独立设置及原专用流程，不接收新任务计划。

要寻找其他角色：先填写游戏路径及独立工作区，可先点击“检查索引兼容性”，只检查分组索引与清单。格式可读后，可点击“扫描游戏资源”。扫描会读取 VFS 和 CHK，首次耗时取决于安装内容和磁盘速度；之后复用已完成文件的缓存。“重新扫描”跳过 CHK 结果复用。取消按钮在“角色与资源”页；也可关闭窗口，工具会停止扫描后退出。

索引格式可读的新版本会标为“尚未验证”，不会声称模型／动画已兼容。未知格式和读取失败保留报告。当前通用化仅覆盖索引读取，旧陈千语提取仍锁定原配置版本。详见[通用兼容架构](D:/AAAChatGPT/2026-10-23/ni/EndfieldChenTool/docs/通用兼容架构.md)。

扫描只产生**名称候选**，不是完整角色确认：压缩、加密、非 ASCII 或其他命名形式可能漏项；共享动作也不会自动关联给所有角色。候选默认不勾选。资源筛选时隐藏的勾选仍保留在计划中，“全选当前列表”只作用于可见条目。

## 3. 工作区和数据

新工作区默认：`D:/AAAChatGPT/EndfieldCharacterWorkspace`。第一次保存计划时建立，要求为空目录或已有兼容标识的角色工作区。它与旧工具工作区不同。

```text
EndfieldCharacterWorkspace/
  character-workspace.json       工作区格式标识
  tasks/
    <任务 GUID>/
      plan.json                 版本、来源、资源、已知依赖、环境选项和各阶段状态
      result.json               最近一次实际 Bundle 提取结果／进度
      bundles/<分组>/*.ab        校验完成的 Bundle
      runs/<运行 GUID>/          独立日志、结果及本次元数据
      objects/result.json       最近一次对象操作结果，与 Bundle 结果分开
      objects/preparation.json  最近一次独立适配包
      objects/unity-last-run.json  最近一次自动 Unity 导入／生成
      objects/<运行 GUID>/       对象快照、列表、选择、导出文件与诊断
  index/
    logs/                       各次扫描日志
    <完整游戏摘要>/
      plaintext-candidates-v2/strict-index-adapters-v1/
        metadata/               解密／解压后的清单与分组索引
        compatibility-*.json    每次兼容性检查报告
        generations/<索引代次>/
          chunks.sqlite         按 CHK 保存的扫描缓存
          catalog.json          最近完成的候选索引
          report.json           扫描覆盖范围及缺失信息
```

设置保存在 `%LOCALAPPDATA%/EndfieldCharacterTool/settings.json`，与旧工具的设置分开。路径填写不代表检查通过；权重检查、Unity 预览和实际播放检查默认未请求。

索引格式标识为 `endfield-character-catalog-v1`，主要字段为：

| 字段 | 说明 |
| --- | --- |
| `gameBuild`、`gameAssemblySha256` | 来源游戏版本及预期摘要；导入不会核对本机游戏 |
| `sourceDescription`、`createdAt` | 来源描述及建立时间；界面另外记录实际导入路径 |
| `compatibilityStatus`、`compatibilityNote` | 格式兼容性状态及限制，不代表资源解码或播放通过 |
| `bundles` | Bundle 的 `id`、`group`、`md5`、`virtualPath`、`dependencyIds`、`missingDependencyNames` |
| `characters` | 角色 `id`、`displayName`、`rootName`、`rootPathId` 和 `resources` |
| `resources` | `id`、`name`、`kind`（Model／Avatar／Animation）、`sourcePath`、`rig`、`backendKey`、`bundleIds`、`association`、`evidence` |

角色、资源和 Bundle 标识不得重复，引用的 Bundle 必须存在，摘要格式必须有效。索引是元数据，不包含运行成功状态；资源路径在这一阶段只用于展示和计划，不用于执行程序。单个 JSON 读取上限为 256 MB，后续大规模索引应改为分页。索引缓存会保存数百 MB 量级的清单与分组数据，但不会复制全部 CHK 或导出所有模型和动画。

## 4. 模块划分

源码根目录：`D:/AAAChatGPT/2026-10-23/ni/EndfieldChenTool`。

```text
Framework/
  Domain/Contracts.cs           资源、角色、索引、计划、阶段状态和扩展接口
  Services/CatalogService.cs    现有配置读取、索引导入、结构校验、搜索
  Services/WorkspaceStore.cs    JSON 原子保存、计划生成、工作区与任务记录
  Services/GameResourceIndexer.cs  异步扫描、子进程进度、取消及结果读取
  Services/BundleExtractionBackend.cs  Bundle 执行、取消及结果核对
  Services/ObjectWorkflow.cs    对象进程、取消与结果核对
  Services/UnityAdaptationRunner.cs  现有项目导入、备份、Unity 调用与取消
  Services/UnityAdaptationResults.cs  原生结果、输入与输出摘要回读
  WorkspaceForm.cs             主工作页面及交互
  ObjectPage.cs                对象选择与导出页面
  AnimationPage.cs             适配规则、包生成、自动 Unity 入口与日志
Program.cs                     默认进入工作台；保留既有陈千语窗口入口
pipeline.py                    既有陈千语提取流程，本次未改动
scripts/package_framework.ps1  独立编译与打包入口
scripts/index_game_resources.py  VFS／名称扫描、缓存和候选聚合
scripts/endfield_manifest.py   清单 Bundle 表及依赖解析
scripts/index_formats.py       格式适配器与历史参考版本识别
scripts/extract_plan_bundles.py  计划执行、实际依赖、文件恢复与结果
scripts/object_pipeline.py    对象输入快照、选择及导出编排
sources/exporters/            模型／动画导出器与实际对象解析器
profiles/known_builds.json      参考摘要记录，不作为读取许可
Crypto/Program.cs             原 VFS 解密及新增 Brotli 清单解压入口
```

扩展接口：

- `IResourceCatalogProvider`：角色配置读取和 JSON 索引读取。
- `IGameResourceIndexer`：异步游戏扫描，含进度与取消。
- `ITaskPlanner`：将角色与资源选择转成计划，展开已记录的 Bundle 依赖图。
- `IExtractionBackend`：已实现 Bundle 后端，支持执行、进度、取消及实际结果；`ObjectWorkflow` 单独管理后续对象解析／导出，保留两阶段记录。

当前扫描解析清单中的直接 Bundle 依赖，并按完整清单路径关联 VFS；不存在或不唯一的映射单独保留，不能当作依赖齐全。候选不生成虚构的 Avatar 或根节点 PathID，计划增加“角色与骨架确认”阶段。动画模式仍待后续对象解析确认。
