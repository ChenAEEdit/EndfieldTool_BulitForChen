# 角色库与动作追加（0.16.0，2026-10-28）

## 结果与使用

新版工作台自动复用同一版本的角色模型，后续批次追加动作，无需手动拆文件或打开复用开关。

1. 使用 `D:/AAAChatGPT/EndfieldCharacterTool-0.16.0/EndfieldChenTool.exe`。
2. 按原流程选择模型、骨架和动作，生成 Unity 预览。首次建立角色库；以后相同模型及单位策略复用已有资源。
3. 点击“打开并播放预览”。固定场景汇总此模型已通过核对的动作，场景只放一个角色。

**已实测：两个不同任务分批导入后，角色库只有一份 FBX，动作目录没有 FBX；模型 GUID、导入设置及角色库记录不变。新旧动作在同一实例上实际 Play 通过。**

新流程从 0.16.0 新生成的包开始生效。历史包、旧模型和历史场景保留，不自动迁移、合并或删除；旧版包仍使用其原有独立目录。

## 保存与复用

- 工作区 `models/<版本摘要>` 保存经过摘要核对的原始模型导出缓存。依据包含游戏程序集与资源清单、实际模型和 Avatar 来源 Bundle/对象及导出器版本，不按角色名称猜测相同模型。
- 相同模型再次准备其他动作时复用导出，跳过模型导出器，独立解码所选动作并保存本批证据。缓存被修改、缺失或出现额外文件时停止，不覆盖原缓存。
- Unity 的 `Assets/EndfieldCharacterLibrary/<版本摘要>/Model` 保存模型、贴图与模型元数据；`Generated` 保存一份角色 Prefab、基础预览材质和校验记录。
- `Assets/EndfieldCharacterExports/<任务>_<批次>` 保存本批动作源、证据、生成动画、控制器、必要的人形 Avatar和审计报告；不再保存另一份模型、贴图、角色 Prefab或独立场景。
- 游戏资源、模型/Avatar 来源、导出器或单位导入策略变化时建立新版本，避免改变旧动画依赖的模型。自动推导与手动单位策略分别保存。
- 源适配包为方便独立备份和其他工程首次导入，仍携带角色资源，但放在稳定的角色库目录。重复导入到 Unity 时只核对并复用，保留原 `.meta` 和 GUID。
- 模型本体、已确认子层级道具、初始显隐、LOD 和材质继续按真实证据恢复。独立道具、必要效果或轨道证据不足时仍按严格模式停止。

## 共享预览与保护

- 固定场景为 `Assets/EndfieldCharacterWorkbench/Preview/CharacterPreview.unity`，首次打开预览时创建，随后保留 GUID更新动作集合。
- 打开时核对相同模型版本的成功动作包；相同动作源与换算规则去重，失败、缺失或修改过的历史包跳过并记录原因。索引可从已导入的配置重建。
- 轻量组合控制器引用已有动画，不复制网格。切换仍执行重绑定，支持逐片段 Avatar、暂停、拖动时间、重播和循环。
- 共享角色与预览实例持续更新动画；复用模型时按当前导入倍率测量，唯一匹配保留层级后的骨骼路径，不重新写入或重新导入共享 FBX。
- 共享模型、材质、Prefab、导入元数据或工具预览被编辑时停止并提示，不覆盖编辑；批处理不切换有未保存内容的其他场景。自定义预览应另存为自己的场景。
- 旧包按原路径打开，新包的工作台打开请求与“定位预览场景”使用共享场景路径。空白启动场景可安全替换，已有内容需保存或明确处理后才能切换。
- 同一角色可在当前 Play 中切换已载入动作；切换到另一角色版本前需先退出 Play。
