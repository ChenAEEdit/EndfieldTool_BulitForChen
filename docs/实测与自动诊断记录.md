## 2. 验证发现并修正的问题

### 后台启动时无法生成场景

第一次真实执行中，FBX、源动画、曲线及 Prefab 已生成，但 Unity 报告不能在未保存的无标题场景旁创建附加场景。

修正：仅在后台启动且当前场景无路径、无根对象时，使用新场景替代该空白启动场景；交互编辑仍保持附加生成方式。失败包保留，没有清空其部分输出。随后重新准备独立包，完整生成与复用通过。

### 通用预览没有正确绑定基础贴图

第一次 Play 数值检查通过，但截图显示大面积发白。原通用模板仅沿用导入材质，没有利用已导出的真实材质槽位。

修正：按 `material_properties.json` 中精确材质名及 `_BaseMap`／`_MainTex` 绑定对应导出贴图，保存独立基础预览材质；辅助眼部／头发阴影采用简单透明替代。没有按“包含 cloth 就取某张图”的方式猜测贴图。

最终截图恢复了基础服装、面部、头发和眼睛颜色。当前仍为基础 Shader 和照明，辅助阴影有替代处理，不代表游戏原渲染已经还原。

## 4. 新增基础诊断

“动画适配”页新增 **查看诊断报告**，读取本次原生报告后生成易读的 `diagnostics.md`。

覆盖：

- 模型导入倍率、动画位置倍率。
- 蒙皮网格、导入顶点、实际引用骨骼。
- 缺失骨骼、无权重顶点、非法权重／骨骼索引、归一化误差。
- 非有限顶点、重复层级路径。
- 每条片段保留曲线、未匹配路径和生成错误。
- 每个基础材质的真实贴图映射及替代提示。

明确非法的骨骼／权重／顶点或重复路径会停止后续生成并保留原生诊断。缺图或基础替代材质保留提示，不把专用 Shader 未复原隐藏成完整还原。

最终两条待机的诊断结果：10 个蒙皮网格、56,698 个 Unity 导入顶点、320 个实际被引用的骨骼；缺失骨骼、无权重顶点、非法权重、超过 1% 归一化误差、非有限顶点、重复路径均为 0；两个片段未匹配路径均为 0。9 个基础材质中有 2 个使用辅助阴影替代。

Unity 导入顶点会因 UV／法线等发生拆分，和 56,490 个原始顶点采用不同统计口径；实际被蒙皮引用的 320 个骨骼也不等于 FBX 全骨架节点总数。权重检查针对当前最多四影响的 Unity 导入结果。
