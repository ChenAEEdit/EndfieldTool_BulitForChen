# v0.1.2：行走时面部变形

## 已确认的原因

1. 共享 `female_walk` 带有另一套面部固定变换。按名字将曲线绑定到陈千语后，96 个面部蒙皮骨骼中的 78 个偏离原始姿势。最大位置差约 19.64 毫米，表现为眼球露白、眉毛下压、嘴唇和脸颊变形。
2. 原基础材质规则将 `M_eyewhiteshadow_common_01` 分配了 `T_actor_chen_cloth_01_D` 衣服贴图，产生眼睛上方的彩色横条。

不能仅凭这些现象判定模型权重错误。第 20 帧对照实验中，只排除共享片段的面部曲线，身体仍播放相同动作，面部就恢复了原始形状；再修正辅助阴影材质后，彩色横条也消失。

## 修正范围

- 从脸、虹膜、眉毛和眼部辅助网格的实际蒙皮引用中得到 96 个面部骨骼，并补入其 2 个祖先节点。保留头部本身的身体动画。
- 生成的 UI 行走预览排除对应的 800 条标量曲线，保留陈千语原始面部姿势。曲线关键帧的最大变化约为 1.07e-6，属于近似常量。
- 原始 Source 动画保留，未改写解包出的源文件。
- 眼白辅助阴影使用半透明基础材质，不再应用衣服贴图。
- 同步更新 `Assets/EndfieldChenTool` 和 `Assets/ChenReextracted` 两个生成入口。

这条行走预览采用中性面部，没有复原独立的眨眼、口型和表情动画；基础阴影材质也不是游戏原着色器的完整复原。

## 本次验证

- 复现了用户截图的第 20 帧，并保存原始面部、原动画、仅身体动画和修正材质四组近景。
- 新生成 UI 片段检查 18 个时刻，包括准确的第 20 帧：98 个面部节点的位置、旋转和缩放检查均通过。
- 实际 Play 模式检查 3 个时刻：98 个面部节点变化数均为 0；已查看实际运行的近景截图。
- 新检查纳入生成与播放的成功条件，不再仅靠整体包围盒、非有限顶点或腿部运动判断。
- 两类动画的网格和实际 Play 检查通过；旧入口重建通过。
