**交付状态：代码、编译及打包完成；新自动生成、场景打开和运行交互均尚未实测，播放效果未验证。** 本阶段没有启动 Unity、Blender、提取器或测试，没有写入现有 Unity 项目。

## 1. 你能怎么使用

工具入口：`D:/AAAChatGPT/EndfieldCharacterTool-Framework/EndfieldChenTool.exe`，窗口为“终末地角色工作台 · 动画预览场景 0.9.0”。

1. 载入已完成 Bundle 提取的任务对象，选择模型根节点、对应 Avatar 和需要的动画。
2. 在“动画适配”确认单位、根位移和排除规则，勾选 **生成可切换、暂停和重播的独立预览场景**（默认勾选）。
3. 点击“生成 Unity 适配包”，得到 0.9.0 新包。
4. 确认页面目标仍是自己需要的现有项目，保存并关闭对应 Unity 编辑器。
5. 点击“导入并生成适配”。本次回执、源文件和输出全部核对后，点击“定位预览场景”或“打开生成目录”。
6. 打开同一个 Unity 项目，在 Project 窗口找到 `Generated/CharacterPreview.unity`，打开后点击 Play，切到 Game 视图使用左侧控制面板。

本机项目仍为 `D:/Unity 3D/Projects/Codex_ZMD`。当前按钮定位文件，不会启动第二个 Unity 编辑器或自动替换你正在编辑的场景。

只需要动画和 Prefab 时，可取消预览场景选项。0.8.0 包继续支持自动导入和回读，但不会凭空增加预览场景；需要该功能时重新准备 0.9.0 包。0.7.0 包仍可手动菜单生成。

## 2. 场景中包含什么

| 内容 | 设计 |
| --- | --- |
| Character | 本次生成 Prefab 的独立实例 |
| Preview Camera | 按模型静止包围盒安排，纯色背景；运行时为控制面板留出区域并适应窗口尺寸 |
| 两盏方向光和环境光 | 基础照明，不复原原游戏渲染 |
| Animation Preview Controls | 运行时面板，引用本次片段和唯一播放状态 |

不修改现有 `Chen_UI_Walk`、`Chen_Reextracted`、待机场景或膝部对照场景。生成器创建独立附加场景，保存后关闭，并恢复原活动场景；不会修改项目构建场景列表。

场景保存的是导入模型静止姿势。生成时不采样动画；播放初始化与切换只在 Play 模式中的控制脚本执行，避免把某一动画帧写成静止姿势。

## 3. 播放面板

- 动画列表及上一个／下一个。
- 暂停／继续、重播。
- 0.1～2 倍速度，只修改本角色 Animator，不改全局时间。
- 播放进度、片段时长和循环／单次标识。
- 拖动时间进度；暂停后可以上一帧／下一帧。
- 相机左转／右转、拉近／拉远、复位。
- 面板可滚动，动画列表另有滚动区域。

循环设置沿用源动画或工作台的明确选项。面板不会为了方便查看而强制循环。切换时重新绑定并使用本次片段唯一状态 ID，避免同名动画或不同轨道集留下前一片段的姿势；该行为尚未经过实际播放验证。

控制脚本使用 Unity 自带即时界面，不增加 UI 插件依赖，也不调用旧版 `UnityEngine.Input` 读取键鼠。当前未提供触屏客户端或手机原生预览；手机上看到的是电脑运行情况。

## 4. 产物与状态

0.9.0 包比此前多一个共享运行时脚本：

`Assets/EndfieldCharacterWorkbench/Runtime/CharacterPreviewControls.cs`

生成目录为：

```text
Assets/EndfieldCharacterExports/<任务短ID>_<准备运行ID>/Generated/
  Clip_<对象ID>.anim
  Character.controller
  Character.prefab
  CharacterPreview.unity       勾选预览场景时生成
  adaptation-result.json
```

原生报告新增 `previewCreated`、`previewScene`，每条动画记录唯一 `state` 路径。回读根据本次配置决定是否必须有场景，检查场景位置、文件摘要及片段状态，确认后把绝对场景路径写入对象记录的 `unityPreviewScene`。

0.9.0 另记录源资源、生成资产及共享脚本的 `.meta` 摘要；回读时核对完整覆盖范围和内容，避免文件本体没变但 GUID／导入设置变化后仍误认资产引用完整。该检查同样尚未运行验证。

场景生成成功仍为 **`adapted_unverified`、`playbackVerified=false`**。文件存在与摘要一致只能说明生成产物匹配，不能证明交互、关节或面部画面正确。

共享编辑器脚本和运行时脚本各有安装摘要和备份。自动生成前后都核对共享脚本；未知或手改版本保留并停止。已知 0.7.0／0.8.0 共享编辑器脚本可以备份后升级。已有包和生成内容继续沿用 0.8.0 的保护与复用规则。

模板编译命令：

```powershell
dotnet build sources/compilation/UnityTemplates/UnityTemplates.csproj --configfile NuGet.Config -p:UseSharedCompilation=false -warnaserror
```

该工程默认使用本机 Unity 路径；其他安装位置可通过 `-p:UnityEditorDirectory=...` 指定。它不是测试工程，不启动 Unity，也不执行模板逻辑。
